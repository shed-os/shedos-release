# Nothing here is a free pass: each path was opened and read before it was written down.
#
# The comparison is blob-to-blob between the carved repository and the monolith files the
# carve took, and every path below is written the way the carved repository holds it
# (`tree/…`, `man/…`, `test/…`) rather than the way the built package installs it, because
# the carved path is what was compared. Every `content` line is pinned
# <monolith blob>..<carved blob>.

# Source package: shedos-hyprland, carved at monolith commit 7b7223a3 and compared against

# --- the four depends edges, one at a time ----------------------------------------
#
# 1. `shedos-system>=2026.05.17` → `shedos-theme-engine>=2026.08.09`. The floor was always
#    about one file: the Lua config dofile()s /etc/shedos/themes/current/palette.lua, and
#    an old renderer meant the config fell back to hardcoded Mocha. The package that
#    renders it is the theme engine now, so that is what the floor names. 2026.08.09 is the
#    engine's first release, which makes it the first version that can write the schema-1
#    outputs this config indexes at all — the floor is exact rather than historical, and it
#    is not vacuous in the other direction: an engine that ever changes SCHEMA_VERSION is a
#    floor this line has to move past.
#
# 2. `shedos-system`, unversioned and NOT the same edge. Dropping the pin outright would
#    have taken the only shedos-system edge with it, and three waybar buttons exec
#    /usr/lib/shedos/run-with-pause.sh, which that package ships. The loss of that edge is
#    the thing worth recording; the pin's version floor moving is the smaller half.
#
# 3. `shedman`. §5.1: the dispatcher the six verbs plug into.
#
# 4. `python-tomlkit`, `python-gobject`, `gtk4`. The dock verb imports tomlkit and the
#    keybindings dialog imports gi/Gtk 4.0 at module load. NONE of the three was declared in
#    the monolith — the desktop's other depends dragged GTK in and the dock verb shipped
#    from a package that declared tomlkit for other reasons, so the gap never showed. It
#    shows now: the pipeline runs each verb out of the built package with nothing else
#    installed.

# `shedos-hyprland-plugin-hyprspace` are gone from depends. They are part of what a ShedOS
