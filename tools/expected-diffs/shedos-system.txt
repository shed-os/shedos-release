# --- (b2) the 15 files with no monolith counterpart --------------------------------
#
# §5.6, the fence library: tree/usr/lib/shedos/pacman-fence. It renders either channel
# block and does the strip-then-append that leaves exactly one canonical pair, canary
# first, byte-idempotent. The install scriptlet here and `shedman migrate` in its own
# repository both ask it; the monolith's three writers are left alone.
#
# §5.5, the shared driver list: tree/usr/share/shedos/nvidia-driver-stack, thirteen package
# names read by nvidia-reap and, from the installer's side, generated into its own copy.
#
# §5.1, the verb contract: tree/usr/share/shedman/verbs.d/<name>.toml for each of the eight
# verbs — encrypt, fingerprint, kernel, key, lock, login, secureboot, tpm2 — each naming the
# verb, shedos-system as its owner, its man page and what it does, every description equal
# to the verb's own --help-summary. lock has no flags and carries completes = false.
#
# test/man/run.sh is new: the monolith's manual suite went with shedman, and this one asks
# the same questions of the pages and the verbs THIS repository ships, deriving both lists
# from the tree rather than keeping them by hand.
#
# test/backfill-uki-cmdline/run.sh is new: the module it wraps is pytest, and the runner
# discovers test/<suite>/run.sh. A missing pytest is a failure there rather than a skip.
#
# Repository scaffolding the carve could not bring and the package does not ship:
# README.md, .gitignore, .github/workflows/ci.yml.
