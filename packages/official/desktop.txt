# GTK/Qt Theming
#
# qt5-wayland + qt6-wayland are runtime support for Qt apps under
# Wayland (calamares uses them). The Qt theming GUIs (qt5ct, qt6ct,
# kvantum) are dropped — most ShedOS user-facing apps are GTK
# (nautilus, file-roller, mako, gnome-disk-utility, gnome-system-
# monitor, etc.). nwg-look + gsettings cover GTK theming. Devs who
# install Qt apps and want to theme them: `pacman -S qt6ct kvantum`.
