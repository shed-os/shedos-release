# AUR packages that exist only for the live ISO / installer environment.
#
# These are listed in packages/aur.txt so build-aur-packages.sh builds
# them locally and bundles them into the airootfs squashfs. Once
# Calamares unpacks that squashfs onto /target, they ride along onto
# the installed system.
#
# What makes them DIFFERENT from regular AUR entries:
#
#   - Excluded from packaging/shedos-meta/PKGBUILD entirely (neither
#     depends nor optdepends). render-meta-depends.sh skips them, so
#     `pacman -Syu shedos-meta` on an installed system does not pull
#     them.
#   - Excluded from the public repo. CI's "Sign + stage packages"
#     step in build-packages.yml unions this list with
#     aur-norepublish.txt to skip signing + uploading to
#     repo.shedos.org/{stable,test}/x86_64/.
#
# Net effect: the package ships once with the ISO and stays at that
# version on the user's system until they remove it. There is no
# update path through ShedOS infrastructure.
#
# Use this list for installer tooling (Calamares and its required
# Calamares-only dependencies) — not for end-user applications, which
# should land in aur.txt (republished) or aur-norepublish.txt
# (visible as optdepends but never republished).
#
# One package per line. Comments with '#' are ignored.
