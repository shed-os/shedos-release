# Packages that exist only for the live ISO / installer environment.
#
# The AUR entries are listed in packages/aur.txt so build-aur-packages.sh
# builds them locally and bundles them into the airootfs squashfs.
# shedos-installer is not an AUR package: it is built from its own
# repository and installed into the ISO by the ISO build. Either way,
# once Calamares unpacks that squashfs onto /target, they ride along onto
# the installed system.
#
# What makes them DIFFERENT from regular AUR entries:
#
#   - Excluded from packaging/shedos-meta/PKGBUILD entirely (neither
#     depends nor optdepends). render-meta-depends.sh skips them, so
#     `pacman -Syu shedos-meta` on an installed system does not pull
#     them.
#   - Excluded from the public repo. CI's "Sign + stage packages"
#     step in build-packages.yml unions this list with
#     aur-norepublish.txt to skip signing + uploading to
#     repo.shedos.org/{stable,test}/x86_64/.
#
# Net effect: the package ships once with the ISO and stays at that
# version on the user's system until they remove it. There is no
# update path through ShedOS infrastructure.
#
# Use this list for installer tooling (Calamares, the ShedOS Calamares
# modules, and their Calamares-only dependencies) — not for end-user
# applications, which should land in aur.txt (republished) or
# aur-norepublish.txt (visible as optdepends but never republished).
#
# One package per line. Comments with '#' are ignored.
#
# calamares is here and not in the monolith's copy, which is a divergence
# and a deliberate one. The monolith's generator learns which ShedOS
# packages the metapackage installs from a list written inside the
# generator, and calamares was never on it, so nothing there ever had to
# say calamares is installer-only. This generator learns them from the
# release manifest, which names every package the channel serves —
# calamares among them — so the exclusion has to be written down or the
# installer would land on every machine that installs shedos-meta. The
# monolith's copy gains the line when the monolith is next open for
# edits; until then this list is ahead of it by one name.

calamares
shedos-installer
