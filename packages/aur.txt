# Auto-renicer — keeps interactive apps responsive while heavy build
# jobs (cargo, gcc, npm) are scheduled at lower priority.
# Pinned to the -git variant: upstream v1.1.1 (the last tagged release
# on AUR `ananicy-cpp`) fails to compile against glibc 2.41+ because
# glibc now declares `sched_attr` / `sched_getattr` which collide with
# `<linux/sched/types.h>`. The post-1.2.0 git snapshot guards the
# include and builds cleanly. `ananicy-cpp-git` provides+conflicts
# `ananicy-cpp`, so the depends string in shedos-system/PKGBUILD
# stays as plain `ananicy-cpp` and resolves via `provides=`.
ananicy-cpp-git

# Fingerprint stack — vendor closed-source bits + the TOD-enabled
# libfprint variant they require. All listed in aur-norepublish.txt
# because the closed-source blobs forbid us hosting them on
# repo.shedos.org. Bundled into the airootfs squashfs at ISO-build
# time so first-boot fingerprint unlock works without a manual AUR
# step.
#
# Why libfprint-tod and not stock libfprint: Arch's stock libfprint
# is built with tod=disabled, so TOD plugins (libfprint-2-tod1-*)
# can't load against it. libfprint-tod is the same upstream sources
# rebuilt with tod=enabled; it provides+conflicts libfprint, so
# pacman swaps stock for the TOD-enabled build at install time and
# fprintd's libfprint dep resolves cleanly.
#
# Each plugin binds to a specific USB ID via udev; the others stay
# inert. libfprint-* forks (e.g. libfprint-goodix-521d) which
# REPLACE libfprint with sources patches are NOT bundled — they
# conflict with each other and with libfprint-tod, so we'd have to
# pick one. `shedman fingerprint detect` points users at the right
# fork when their sensor isn't in the bundle.
libfprint-tod
libfprint-2-tod1-broadcom
libfprint-2-tod1-broadcom-cv3plus
libfprint-2-tod1-elan
libfprint-2-tod1-goodix
libfprint-2-tod1-goodix-v2
libfprint-2-tod1-synatudor-git
libfprint-2-tod1-xps9300-bin
