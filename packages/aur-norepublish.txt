# AUR packages that MUST NOT be republished to repo.shedos.org.
#
# These are listed in packages/aur.txt so the ISO build pacstrap can install
# them onto the airootfs at mkarchiso time (legally equivalent to any user
# running `yay -S <pkg>` themselves — the vendor's installer runs locally,
# their binaries are fetched from their CDN, nothing transits ShedOS
# infrastructure).
#
# What we CAN'T do is take those fetched binaries, wrap them in a
# .pkg.tar.zst signed by the ShedOS repo key, and serve that file from
# repo.shedos.org. The vendors' EULAs don't grant that redistribution right.
#
# Because we still bundle them into the ISO, every fresh install ships
# with these apps already installed. They're listed as optdepends= on
# shedos-meta for visibility — `pacman -Syu shedos-meta` does not pull
# them. Users who later remove them can reinstall via `shedman install`
# (which falls back to yay).
#
# One package per line. Comments with '#' are ignored.

postman-bin
claude-code-bin
jetbrains-toolbox
